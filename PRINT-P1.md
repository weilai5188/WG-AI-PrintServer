# WG AI Print P1 (experimental)
Independent derivative of WG-AI-PrintServer-P0. Original CW repository and firmware are not modified.
Imports LoveLH ESP32-S3-USB-PrintServer 2.9.7 USB printer, printer database, RAW print server and crash logging; MIT license preserved in main/wg_print/LICENSE-LoveLH.txt. Compatibility headers replace Arduino String, timing, PSRAM and TCP APIs with ESP-IDF/lwIP. Original USB event handling stays in UsbPrinter; no second USB probe or competing library event loop.
Build target: ESP-IDF 5.5.2, bread-compact-wifi-lcd-240x240, 16MB flash (verify against hardware). Existing Wi-Fi and Xiaozhi audio/UI retained. Printer native USB in Host mode; UART for power/logs. RAW 9100 on LAN; no web administration, IPP, USB/IP or printer OTA in P1. Do not expose RAW port to public Internet. MCP self.printer.get_status provides status and IP; no screen overlay yet. Existing Xiaozhi OTA path has not been validated with active printing; avoid OTA during print tests.
P1 is source only: no complete ESP-IDF build or device test was run in this environment. Validate build first. Preserve original standalone print firmware and CW image; flash P1 only after successful build. Test chat, USB recognition, Windows L1300 driver RAW 9100, then concurrent chat+print, reconnect, large photo. Before reconnecting phone to native USB, revert hardware VBUS jumper if required by board design.
